## 🚀 Projects Section (Most Important)

**Location**: Fourth section, central focus

**Contents**: 4 Premium Project Cards

### Project 1: ResolveIT
- **Summary**: Interactive IT support operations demo
- **Problem**: Static dashboards do not show how support work changes the employee experience
- **Features**:
  - Technician workspace and employee self-service portal
  - Ticket lifecycle, SLA triage, device health, and VPN diagnostics
  - Internal notes, public updates, and local browser state
- **Tech**: Next.js, TypeScript, React, Tailwind CSS, Lucide React, Recharts
- **Actions**: Live Demo, GitHub, Case Study

### Project 2: RallyTab
- **Summary**: Sports-bar ordering and operations platform
- **Problem**: Guest ordering, kitchen work, and staff operations need connected views
- **Features**:
  - Table-aware QR ordering
  - Kitchen queue and service request tracking
  - Staff dashboard for tabs, tables, and menu availability
- **Tech**: Next.js, TypeScript, React, Tailwind CSS, Local Storage
- **Actions**: Live Demo, GitHub, Case Study

### Project 3: SkillBridge AI
- **Summary**: Tutoring dashboard and learning workflow
- **Problem**: Tutors need fast ways to translate progress data into next steps
- **Features**:
  - Student progress and skill gap review
  - Practice plan and parent summary workflows
  - Fictional student data for safe portfolio review
- **Tech**: Next.js, TypeScript, React, Tailwind CSS
- **Actions**: Live Demo, GitHub, Case Study

### Project 4: Seamless
- **Summary**: Chrome extension for reusable writing templates
- **Problem**: Repeated browser writing needs a faster, local-first workflow
- **Features**:
  - Template library with folders, search, and favorites
  - One-click snippet insertion
  - Privacy-first local browser storage
- **Tech**: TypeScript, Chrome APIs, Tailwind CSS, Local Storage
- **Actions**: Chrome Store, GitHub, Case Study

**Purpose**: Demonstrate real-world software development capability

**Design**: Case-study format, premium cards with shadows, clear hierarchy, and dedicated project pages

## 🎨 Overall Design System

### Colors
- **Primary**: Blue (#2563eb) - buttons, accents, links
- **Secondary**: Dark Navy (#0f172a) - headings, footer
- **Text**: Dark Gray (#1e293b) - body text
- **Light Text**: Medium Gray (#64748b) - descriptions
- **Background**: White / Light Gray (#f8fafc)

### Typography
- **Font**: Inter (Google Fonts)
- **Headings**: Bold, dark navy
- **Body**: Regular, dark gray
- **Hierarchy**: Clear size scale from 48px to 14px

### Spacing
- **Sections**: Large vertical spacing (6rem)
- **Cards**: Consistent padding (2rem - 3rem)
- **Elements**: Systematic spacing scale

### Effects
- **Hover**: Subtle lift and shadow on cards
- **Transitions**: Smooth 200ms animations
- **Shadows**: Layered shadows for depth
- **Borders**: Subtle borders with hover color change

### Responsive
- **Desktop**: Full multi-column layouts
- **Tablet** (< 968px): Adjusted columns
- **Mobile** (< 768px): Single column, stacked
- **Small Mobile** (< 480px): Optimized text sizes

## 🎯 User Journey

1. **Land on Hero**: Immediate understanding of who Saleem is
2. **Read About**: Learn about approach and capabilities
3. **Scan Skills**: Quick verification of technical skills
4. **Explore Projects**: Deep dive into real work (main conversion point)
5. **Review Services**: Understand what can be offered
6. **Contact**: Easy path to get in touch

**Total Scroll Time**: ~2-3 minutes for full review
**Recruiter Scan Time**: ~30 seconds to get key information

---

## 📱 Mobile Experience

All sections adapt gracefully:
- Navigation becomes hamburger menu
- Multi-column layouts stack vertically
- Cards remain full-width for readability
- Touch-friendly button sizes
- Optimized text sizes
- Maintained visual hierarchy

## 🎓 Section Priorities

For recruiters, the most important sections are:

1. **Hero** (5 seconds): Who are you?
2. **Projects** (60 seconds): What have you built?
3. **Skills** (15 seconds): What technologies?
4. **Contact** (10 seconds): How to reach you?

The portfolio is optimized for this scanning pattern.
